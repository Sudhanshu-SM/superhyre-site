# X2 results, 12 Oct 2026 (round 3): roles, isolation, numbers, on the fixed build

Re-tester X2. Scope: (1) the whole r2 security and isolation matrix as a regression, (2) the fixes aimed at it, (3) the new campaign and
teammate resolvers (`agent/campaign-target.ts`, `capabilities/team-lookup.ts`), (4) the numbers: one funnel, every surface.

Environment: console :5173, API :8090, gateway :8100, Postgres :55432 read-only, Qdrant :56333. Everything below was seen in the running
product through the API (real tokens from the auth stand-in) and read-only psql. One Chrome at a time on :9362 (only where a page is
the thing being checked). I built my own organisation (X2 Co, schema `tenant_x2_co`: owner `x2.owner@x2-co.io`, admin `x2.admin@`,
recruiters `x2.rec1@`, `x2.rec2@`, a removed member `x2.dr1@`), a second organisation (X2 Out Co: `x2.outowner@x2out-co.io`,
`x2.outrec@`) and a Personal-only person (`x2.solo@gmail.com`). The demo organisation (`own@fn3qa.dev`) was read only.

World: 12 campaigns in X2 Co (org-shared x2, owner-private with a hidden client, member-only, client campaign, admin-only, two
recruiter-owned), 4 clients, 13 named candidates (imports, manual adds per role, unclaimed, hidden), tasks, schedules, do-not-contact
entries, exports, 9 calls with real WAV recordings and transcripts (one carrying an injection line), memory at every level made through
the agent and its approval cards, Personal data for owner, rec1 and solo, and the same-named person with the same email, phone and
LinkedIn in X2 Out Co.

## 4. Numbers: one funnel, every surface

Definitions are `pipeline/counts.ts`: found = search results (campaign_seen, source ours or crustdata), shortlisted = everyone on the board
(passed included), contacted = a message went out or the person went to outreach or a reply is logged, replied is part of contacted,
interviewing = entered interviewing at any time, hired = at hired now.

Shapes built through the product (API) in X2 Co plus three real campaigns of the demo organisation (read only):

- **X2NUM Full Funnel** (found 12 by search + 1 added by hand; 8 on the board; 5 emails sent through the Gmail simulator, 2 replies logged, one person interviewing, one hired through interviewing, one passed after contact, one passed never contacted): expected found 12, shortlisted 8, contacted 5, replied 2, interviewing 2, hired 1; rates 58 / 63 / 40 / 40 / 50; stages 2 / 2 / 1 / 1 / 2 passed.
- **X2NUM Manual Skips** (6 added by hand, none found; one moved into outreach with nothing sent, one straight from the shortlist to hired, one straight to interviewing, two passed never contacted): expected found 0, shortlisted 6, contacted 1, replied 0, interviewing 1, hired 1; rates null / 17 / 0 / 0 / 0.
- **X2NUM Found Only** (9 found, nobody on the board): 9 / 0 / 0 / 0 / 0 / 0, rates null.
