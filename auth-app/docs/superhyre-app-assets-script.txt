GENERATE THEM ONE BY ONE
------------------------

  side-by-side variations.

  E3-empty-columns.png. Same capitals, hyphens and spelling; no spaces, no extra words.
- Keep all 62 files in one folder and tell me where it is.

Before you start
----------------
- Attach the sign-in artwork (superhyre-site/assets/access-art.webp) as the style
  reference if your generator accepts one. Every image matches that look.
- For each prompt you can ask for 3 or 4 variations, then keep ONE: the closest to the
  sign-in art, with no garbled text (screens and cards show only grey or orange bars).
- Use the size given on each "SIZE:" line.
- Generate the P2 images first, P3 after.
