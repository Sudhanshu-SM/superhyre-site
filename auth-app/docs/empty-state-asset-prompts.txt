SUPERHYRE EMPTY-STATE, ERROR AND MILESTONE ASSETS: ALL PROMPTS (42 images)
==========================================================================

WHAT THIS IS
One self-contained prompt per asset. Every prompt opens with the SuperHyre design-system block
(style, palette, composition, mood, canvas), then names the single object to draw. Paste ONE prompt,
generate, save the image under the file name shown, then the next.

THE SYSTEM IN ONE GLANCE
- Style: flat vector graphic illustration, solid fills, no outlines, no gradients, no shadows, no texture.
  Same family as the sign-up flow art (the sprout pot, the sofa, the lamp, the envelope).
- Palette: peach #F8D8C8, blush #FCE9E1, soft coral #F08858, terracotta brown #B06038,
  deep brown #382018 (tiny details), vivid orange #E85818 (one small accent per image).
- One hero object per image, never repeated across images (that is why a bonsai is for "no tasks"
  and nothing else). No people, hands, faces, animals, text or numbers in any image.
- Mood: calm, relaxed, quietly warm. Errors are never red or scary; empty is never sad.
- Canvas: 2048 x 2048, square, flat pure white background so it can be cut out (same pipeline as the
  background-removed sign-up set). Object at about 55% of the canvas, centred.

IF YOUR TOOL ALLOWS A REFERENCE IMAGE
Attach these from superhyre-site/assets/sign-up-flow-transparent/props/ : prop-plant.png, prop-sofa.png,
prop-lamp.png. They set the exact shape language, colours and flatness. Use the same one every time.

SAVE AS
Exact file names below, .png. Put them all in one folder and tell me where; I will cut the white
background, trim, convert to WebP and wire each into its screen.

REUSE (no new image needed)
  - Sign-up: ask to join your team  -> reuse prop-door.png (already in the sign-up set).
  - Sign-up: waiting for an admin to approve -> reuse prop-sofa.png (already in the sign-up set).
  - Campaign page with no campaign selected -> keep the existing code-drawn WaitingFolder in NoCampaign.tsx.
