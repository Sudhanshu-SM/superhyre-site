## Before you start

1. **Attach the four reference images** in `~/Downloads/superhyre-initial-assets/references/`: `1-tara-and-hyre.png`, `2-kabir.png`, `3-meera.png`, `4-props.png`.
2. **One image per request**, never a grid or sheet (batch 1's slivers and boxes came from cropping a sheet).
3. **Transparent background** (except the two email headers). If the tool can't do alpha, generate on pure white and send them over; I'll key them out.
4. **Size:** use the size line in each prompt. Heroes at least 1920×1440.
5. **Name each file** with the id in its heading, e.g. `empty-forms.png`, and drop them in one folder; I'll clean, check and centre them like batch 1.

Tool notes: ChatGPT / GPT-image: attach the references, paste the prompt, ask for transparent background. Midjourney: use the references as `--cref` and `--sref`, add `--style raw --stylize 75` and the aspect, then remove the background. Ideogram / Flux: reference images in, prompt as is, fixed seed per group.
