SUPERHYRE SIGN-UP ASSETS

This package contains 111 individual PNG assets generated from the supplied per-asset prompt file.
Each PNG is stored in its prompt-defined group folder, and manifest.json records its filename,
folder, dimensions, asset number, and generation method.

Character hero poses were generated as individual flat-vector illustrations and resized onto the
requested white canvas. Geometric icons, dials, props, scenery, and animation frames were rendered
as crisp vectors from their individual specifications for consistent geometry and palette.
The reference contact sheet says 106 PNGs, but the accompanying individual prompt file numbers
111 assets; this package follows the individual prompt list.
